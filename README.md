# Partitioning과 연계

### 차수 줄이기

sender 집합에 빈 크기 B=4, $x=\{x_1, x_2, x_3, x_4\}$

- 파티셔닝 적용 ( $\alpha = 1$ )
    - sender는 4개의 데이터를 무작위로 2개씩 나누어 2개의 파티션을 만듦
    - 파티션 1: $\{x_1, x_2\} \rightarrow$ 다항식 $P_1(y) = (y-x_1)(y-x_2)$ (최대 차수 2)
    - 파티션 2: $\{x_3, x_4\} \rightarrow$ 다항식 $P_2(y) = (y-x_3)(y-x_4)$ (최대 차수 2)
- 결합 효과
    - 통신량 절감: 수신자는 $y^4$ 까지 도달하기 위한 거듭제곱 값들을 계산해서 보낼 필요 없이, $y^2$ 까지만 커버하는 더 적은 양의 암호문만 전송하면 됨
    - 연산 효율: 송신자는 수신자가 보낸 $y^1, y^2$ 암호문을 파티션 1 과 파티션 2 에 동시에 재사용 하여 계산할 수 있으므로, 연산 비용이 파티션 개수( $\alpha$ )만큼 크게 절감됨.

# 차수 설정 변수

### 변수 역할

- $\ell$ : 간격 설정
- $j$ : $2^{\ell j}$ 를 통해 차수를 점프시킴
    - $1 \leq j \leq  \left \lfloor \frac{log_2(B')}{\ell} \right \rfloor$
- $i$ : 점프한 구간 내에서 세부 항목 만들기
    - $1 \leq i \leq 2^{\ell}-1$

### 예제

$B'=16$이고, $\ell = 2$인 경우

- i → 1, 2, 3
    - $1 \leq i \leq 2^{2}-1$
- j → 0, 1, 2
    - $1 \leq j \leq  \left \lfloor \frac{log_2(16)}{2} \right \rfloor$
- receiver가 계산해서 보내는 값
    - j = 0
        - $y^1, y^2, y^3$
    - j = 1
        - $y^4, y^8, y^{12}$
    - j = 2
        - $y^{16}$

# 차수 조합으로 생성

### 예제

$B'=16$이고, $\ell = 2$인 경우

- receiver가 계산해서 보내는 값
    - j = 0
        - $y^1, y^2, y^3$
    - j = 1
        - $y^4, y^8, y^{12}$
    - j = 2
        - $y^{16}$
- receiver가 계산하지 않은 값 생성
    - 11을 생성하는 경우
        - 진법의 $base = 2^{\ell} = 2^2 = 4$
        - $11 = 2(=i) \cdot 4^{1(=j)} + 3(=i) \cdot 4^{0(=j)}$
        - sender는 receiver가 보낸 재료 중 $y^8$ ( $j=1, i=2$ )과 $y^3$ ( $j=0, i=3$ )을 가져와서 둘을 곱하기만 하면 $y^{11}$ 이 완성
